# Славянский базар в Витебске

**Ссылка на сайт:** https://justashrimpy.github.io/SlavianskiBasar/

Информационный сайт о международном фестивале искусств «Славянский базар в Витебске».

## 1. Общие сведения

**Название проекта:** Сайт «Славянский базар в Витебске»  
**Тип проекта:** Информационный веб-ресурс  
**Тематика:** Международный фестиваль искусств «Славянский базар в Витебске»  

**Цель проекта:** Создание удобного информационного сайта, посвящённого международному фестивалю искусств «Славянский базар в Витебске». Сайт призван знакомить пользователей с историей фестиваля, его программой, площадками и особенностями посещения.

**Задачи проекта:**
- Предоставление общей информации о фестивале.
- Отображение ключевых фактов и цифр о фестивале.
- Визуализация истории фестиваля в форме хронологии.
- Информирование о площадках проведения мероприятий.
- Предоставление практических советов посетителям.
- Проверка знаний о фестивале с помощью интерактивного квиза.
- Обеспечение возможности обратной связи через контактную форму.

## 3. Структура сайта

Сайт содержит следующие разделы:

1. **Главный экран (Hero)** — краткое описание фестиваля, ключевые данные и призыв к действию.
2. **Факты и цифры** — блок с основными показателями фестиваля: год основания, количество стран-участниц, число зрителей, длительность и количество конкурсов.
3. **Зачем посещать Славянский базар** — три аргумента в пользу посещения фестиваля: музыка и искусство, атмосфера праздника, культурный обмен.
4. **История фестиваля** — хронологическая лента ключевых событий с 1988 по 2026 год.
5. **Площадки фестиваля** — информация о сценах и площадках Витебска, на которых проходят мероприятия.
6. **Советы посетителям** — практические рекомендации по посещению фестиваля.
7. **Квиз** — интерактивная викторина для проверки знаний о фестивале.
8. **Контактная форма** — форма для обратной связи.
9. **Footer** — завершающий блок с информацией о проекте.

## 9. Реализация интерактивных элементов

- **Переключение языка** — реализовано через `LanguageContext`, хранит текущий язык и загружает соответствующие переводы из `src/translations/index.js`.
- **Переключение темы** — `ThemeContext` переключает атрибут `data-theme` на `<html>`, CSS-переменные пересчитывают цвета.
- **Анимированные числа** — в блоке «Факты и цифры» используется `IntersectionObserver` и `requestAnimationFrame` для плавного счёта.
- **Хронология** — секция «История фестиваля» отображает события по годам из массива переводов.
- **Площадки** — вкладки с переключением между группами площадок через `useState`.
- **Квиз** — `Quiz.jsx` управляет состоянием текущего вопроса, подсчитывает правильные ответы и показывает результат.
- **Контактная форма** — собирает данные и формирует `mailto:`-ссылку для отправки письма.

## 10. Используемые CSS-свойства и JS-методы

### CSS
- CSS-переменные (`:root` и `[data-theme]`) для переключения цветовых тем.
- Flexbox и Grid для раскладки карточек и секций.
- `@media` для адаптивной вёрстки.
- `backdrop-filter`, `box-shadow`, `transition` для визуальных эффектов.
- `color-mix` для создания полупрозрачных тонов в светлой/тёмной теме.

### JavaScript / React
- React hooks: `useState`, `useEffect`, `useRef`, `useContext`.
- `React.lazy` и `Suspense` для отложенной загрузки компонентов.
- `IntersectionObserver` для анимаций при появлении в viewport.
- `requestAnimationFrame` для анимаций частиц и чисел.
- Canvas API для отрисовки фоновых эффектов.

## 11. Тема и визуальные решения

Сайт посвящён фестивалю, поэтому выбрана праздничная оранжевая палитра. Оранжевый цвет ассоциируется с тёплой атмосферой, сценическим светом и летними концертами. Светлая и тёмная темы обеспечивают комфортное чтение в разных условиях.

Фон содержит анимированные частицы и звёзды в оранжевых тонах, что создаёт ощущение праздничного пространства. Звезда в логотипе отсылает к «Площади Звёзд» в Витебске, где увековечены имена лауреатов фестиваля.
